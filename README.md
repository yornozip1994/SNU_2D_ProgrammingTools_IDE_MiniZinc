# SNU 2D Programming Tools: MiniZinc IDE 🎨

Welcome to the SNU 2D Programming Tools for MiniZinc! This repository provides an integrated development environment (IDE) tailored specifically for the MiniZinc programming language within the context of SNU's 2D programming framework. Whether you're a beginner looking to learn or an expert aiming to optimize your projects, this tool will enhance your programming experience.

## Features 🌟

- **User-Friendly Interface**: The IDE offers an intuitive layout that simplifies the coding process.
- **Syntax Highlighting**: Enjoy color-coded syntax that enhances readability and helps prevent errors.
- **Integrated Debugging Tools**: Debugging features assist in quickly identifying and fixing issues.
- **Version Control**: Easily manage different versions of your MiniZinc files.
- **Project Templates**: Start new projects with predefined templates that fit various needs.
- **Community Support**: Engage with a growing community of users and developers for support and collaboration.

## Installation ⚙️

To get started, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yornozip1994/SNU_2D_ProgrammingTools_IDE_MiniZinc.git
   ```
   
2. **Navigate to the Directory**:
   ```bash
   cd SNU_2D_ProgrammingTools_IDE_MiniZinc
   ```

3. **Install Dependencies**:
   Use the following command to install all necessary dependencies:
   ```bash
   npm install
   ```

4. **Launch the IDE**:
   Start the IDE using the command:
   ```bash
   npm start
   ```

## Usage 📚

Once the IDE is running, you can start by creating a new MiniZinc project. Here’s a brief overview of how to use the main features:

- **Create a New Project**: Select the "New Project" option from the menu.
- **Open Existing Projects**: Use "Open Project" to access your previously saved work.
- **Write Code**: The editor supports MiniZinc syntax. Take advantage of the syntax highlighting as you code.
- **Debugging**: Set breakpoints and use the integrated debugging tools to step through your code.
- **Compile and Run**: Use the "Run" button to compile and execute your MiniZinc program.
